# 磁盘带宽统计 skill

从 **iostat 逐秒采样文件** 统计磁盘真实带宽（平均/峰值/tps），核心目的是**防止把测试结束前不满 1s 的收尾残差样本平均进均值**，导致磁盘带宽被严重低估。

> 背景教训：曾用 `iostat -d <dev> 1 > out.disk` 采 4M IO 测试，bench 31.1s 结束但 iostat 最后一个 1s 窗口只覆盖了 bench 尾部 ~0.x 秒（残差样本：写 379.8 MiB/s、读 1088.2 MiB/s）。若把残差平均进去，磁盘均值从 2569/6587 被拉低到 2500/6149（写 -2.7%、读 -6.6%），造成"应用层带宽与磁盘带宽不一致"的假象。**剔除残差后稳态均值与应用带宽差异 <0.3%。**

## 适用输入

```bash
# 采样命令（测试期间后台并行）
iostat -d <DEV> 1 > /tmp/${TAG}.disk 2>&1
```

`iostat -d` 输出结构（重点在设备行）：

```
Device             tps    kB_read/s    kB_wrtn/s    kB_dscd/s    kB_read    kB_wrtn    kB_dscd
nvme3n1          60.36       150.59       553.16       506.08 7254687936 26647831766 24379867512   <- 首行：开机累计均值，必须剔除

nvme3n1       20526.00         0.00   2627328.00         0.00          0    2627328          0     <- 每秒一行：真实瞬时速率
...
```

设备行字段：`$1=Device $2=tps $3=kB_read/s $4=kB_wrtn/s $5=kB_dscd/s`。

## 核心规则（防止均值被拉低）

1. **剔除首行累计均值**：`iostat -d` 的第一条设备行是自开机以来的累计平均（tps 通常是几十、速率小），不是测试窗口数据，必须剔除。判别：该行 `tps` 远小于稳态（如 <1000），或速率列远低于稳态。
2. **剔除收尾残差样本**：测试结束后 iostat 仍在跑，最后一两个 1s 窗口只覆盖 bench 尾部不满 1s 的真实 IO + 大部分空闲，速率骤降。判别：速率从稳态水平（如 2500 MiB/s）突然掉到远低于稳态（如 <40% 稳态值）。
3. **用速率阈值过滤**：只统计"满负载稳态样本"。稳态阈值按实际稳态量级设定，通常取稳态水平的 ~20-40% 作为下界（宁严勿松），确保残差进不来：
   - 写：`$4 > 稳态量级 × 0.2`（如稳态 ~2500 MiB/s → 阈值 ~1000 MiB/s，即 `$4>1000000`，单位 kB/s）
   - 读：`$3 > 稳态量级 × 0.2`（如稳态 ~6500 MiB/s → 阈值 ~5000 MiB/s，即 `$3>5120000`）
4. **结果交叉验证**：稳态磁盘均值必须与应用层带宽（总字节/总耗时）吻合，**差异应 <1%**。若差异 >2%，几乎总是残差/首行没剔干净或窗口对齐问题，回头检查原始样本序列。

## 统计命令

```bash
# 写带宽（稳态均值/峰值/tps）。阈值示例：稳态 ~2.5 GiB/s → kB/s 阈值 ~1,000,000
awk '/^'"$DEV"'/ && $4>1000000 {s+=$4; t+=$2; n++; if($4>p) p=$4}
     END{printf "DISK_WRITE n=%d avg=%.1f MiB/s peak=%.1f MiB/s avg_tps=%.1f\n", n, s/n/1024, p/1024, t/n}' /tmp/${TAG}.disk

# 读带宽（稳态均值/峰值/tps）。阈值示例：稳态 ~6.5 GiB/s → kB/s 阈值 ~5,000,000
awk '/^'"$DEV"'/ && $3>5000000 {s+=$3; t+=$2; n++; if($3>p) p=$3}
     END{printf "DISK_READ n=%d avg=%.1f MiB/s peak=%.1f MiB/s avg_tps=%.1f\n", n, s/n/1024, p/1024, t/n}' /tmp/${TAG}.disk
```

> 单位：iostat 列是 kB/s（1024 字节），除 1024 得 MiB/s。
> awk 阈值写成裸数字不要带逗号/下划线（POSIX awk 不支持）。

## 诊断流程（结果异常时）

1. **打印原始样本序列**，肉眼确认稳态区间与残差样本位置：

```bash
grep "^$DEV" /tmp/${TAG}.disk | awk '{printf "tps=%s rd=%s wr=%s\n", $2, $3, $4}'
```

2. 若序列尾部出现**速率骤降的非零行**（如 2571 → 379 → 0），该 379 行就是收尾残差，必须排除。
3. 若均值 vs 应用带宽差异 >2%：
   - 检查是否把首行累计均值（tps 小、速率低）算进去了 → 用速率阈值过滤即可排除；
   - 检查阈值是否设得过松（残差仍 > 阈值）→ 调高阈值；
   - 检查采样是否覆盖了测试启动/结束的 ramp-up/ramp-down 秒（可选：与应用耗时窗口对齐，只取与 bench 运行重叠的样本）。

## 报告格式（带宽部分）

| 模式 | 稳态均值 | 峰值 | 均值 tps | 稳态样本数 |
|------|---------|------|---------|--------|
| 写 | x.x MiB/s | x.x MiB/s | xxxx | N |
| 读 | x.x MiB/s | x.x MiB/s | xxxx | N |

并附一句验证：`磁盘稳态均值与应用带宽差 <1%（写 x vs y、读 x vs y），磁盘为当前瓶颈 / 磁盘非瓶颈`。

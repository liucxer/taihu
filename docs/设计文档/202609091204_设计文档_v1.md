这个库主要功能是，对外提供 object读写接口。 
外部接口： 
NewStorage(ctx context.Context, rocksdbDir, nvmePath string) *Storage
(s *Storage) Get(ctx context.Context, key string, off, limit int64) (io.ReadCloser, error) 
(s *Storage) Put(ctx context.Context, key string, in io.Reader) error 
(s *Storage) Delete(ctx context.Context, key string) error 
 
外部接口依赖底层存储接口实现。
key和segmentID, off的映射关系保存在rocksdb中。 当前工程依赖golang版本的rocksdb库

底层存储接口 
NewDevice(ctx context.Context, nvmePath string) *Device
(d *Device) append(ctx context.Context, segmentID int64, off int64, data io.Reader) error 
(d *Device) read(ctx context.Context, segmentID int64, off int64, limit int64)  io.Reader 
(d *Device) delete(ctx context.Context, segmentID int64) error 

缓存设计

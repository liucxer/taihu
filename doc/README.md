# doc/ 文档索引 —— 哪一份是现行的

本目录共 **69 篇**：设计文档 10、性能测试报告 58、部署记录 1。这份索引回答一个问题：
**要看某个主题，该读哪一篇**，以及其余各篇处于什么状态。

状态标签的判定**只依据文档自身的陈述**（自述的「当前实现」「复测对象」「基线 commit」「前置」等），
每条标签都在下面注明依据 —— 本文不改写任何文档，也不凭文件名日期臆断。

| 标签 | 含义 |
|---|---|
| 【现行】 | 描述与当前代码/部署一致，可作权威参考 |
| 【现行·总纲】 | 现行，且是其他文档的上位综述 |
| 【部分被取代】 | 部分章节仍有效，其余已过时 |
| 【已被 ⟨X⟩ 取代】 | 结论被 X 篇覆盖或吸收，留作演进证据 |
| 【并列参考】 | 未被取代，但测的是别的维度（列在其系列条目里） |
| 【历史存档】 | 已无现行价值，仅存演进过程 |

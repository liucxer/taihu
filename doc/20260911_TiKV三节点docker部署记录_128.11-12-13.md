# TiKV 三节点集群 Docker 部署记录（128.11 / 128.12 / 128.13）

> 日期：2026-09-11
> 目的：为 taihu 集群支持（缓存场景：首写本地 + 索引锚定 + 回源兜底）提供注册中心与索引后端，见《20260911_taihu集群支持设计文档.md》
> 版本：PD/TiKV v7.5.6（ukv 镜像）

## 1. 集群拓扑

| 节点 | 角色 | PD 容器 | TiKV 容器 | 端口 | 数据目录 |
|------|------|---------|-----------|------|----------|
| 100.71.128.11 | pd1 + tikv1 | pd1 | tikv1 | PD 2379/2380，TiKV 20160/20180 | /var/lib/jenkins/tikv3 |
| 100.71.128.12 | pd2 + tikv2 | pd2 | tikv2 | PD 2379/2380，TiKV 20160/20180 | /var/lib/jenkins/tikv3 |
| 100.71.128.13 | pd3 + tikv3 | pd3 | tikv3 | PD 2379/2380，TiKV 20160/20180 | /mnt/nvme0n1/tikv3 |

- 架构：3 PD 组成 etcd quorum + 3 TiKV store，单机单实例（无多副本部署）
- 网络：全部容器 `--network host`（本机直通端口，避免 bridge 转发开销与端口映射）
- 自愈：容器 `--restart unless-stopped`

## 3. 镜像准备（save/load 离线分发）

内网 registry（registry.paas → 100.71.8.120:443）在 128.11 上连接被拒，节点无法直接 pull。128.13 已有历史部署遗留的 ukv 镜像，采用 docker save 导出 + 节点间 9527 直传 + docker load 分发：

```bash
# 128.13：导出并压缩（693MB）
docker save registry.paas/nefs/ukv_pd_arm:v7.5.6 registry.paas/nefs/ukv_server_arm:v7.5.6 | gzip -1 > /tmp/ukv-images.tar.gz

# 128.11 / 128.12：从 128.13 拉取并加载（节点间 ~17s）
curl -s -o /tmp/ukv-images.tar.gz -H "X-Token: 95279527" \
  "http://100.71.128.13:9527/download?path=/tmp/ukv-images.tar.gz"
docker load -i /tmp/ukv-images.tar.gz
```

镜像信息：

| 镜像 | 入口 | 大小 |
|------|------|------|
| registry.paas/nefs/ukv_pd_arm:v7.5.6 | /pd-server | 206MB |
| registry.paas/nefs/ukv_server_arm:v7.5.6 | /tikv-server | 916MB |

## 5. PD 部署

每节点一条 `docker run`，`--initial-cluster` 三成员一次性初始化：

```bash
# 128.11
docker run -d --name pd1 --network host --restart unless-stopped \
  -v /etc/localtime:/etc/localtime:ro -v /var/lib/jenkins/tikv3:/nefsdata/tikv \
  registry.paas/nefs/ukv_pd_arm:v7.5.6 \
  --name=pd1 --data-dir=/nefsdata/tikv/pd \
  --client-urls=http://100.71.128.11:2379 --advertise-client-urls=http://100.71.128.11:2379 \
  --peer-urls=http://100.71.128.11:2380 --advertise-peer-urls=http://100.71.128.11:2380 \
  --initial-cluster=pd1=http://100.71.128.11:2380,pd2=http://100.71.128.12:2380,pd3=http://100.71.128.13:2380

# 128.12（ip 换成 100.71.128.12，--name=pd2，data-dir 挂 /var/lib/jenkins/tikv3）
# 128.13（ip 换成 100.71.128.13，--name=pd3，data-dir 挂 /mnt/nvme0n1/tikv3）
```

## 6. TiKV 部署


## 9. 注意事项

- **内网 registry 不可达**：新增节点部署需继续走 save/load 分发，或恢复 registry.paas 连通后改为直接 pull
- **host 网络 + 固定端口**：三节点 PD/TiKV 端口相同，依赖 host 网络隔离，跨机互不冲突；同一节点不可再起第二个实例（端口占用）
- **数据目录与裸盘隔离**：集群数据在已有挂载盘上，与 taihu-server 裸盘（nvme1/2/3n1）互不影响
- **磁盘空间**：128.12 根分区 99% 满（/ 仅剩 1.9G），数据目录落在 /var/lib/jenkins（1.4T 可用）不受影响；部署镜像/日志等避免写根分区
- **重启自愈**：容器配置了 --restart unless-stopped，节点重启后 PD/TiKV 自动拉起，PD 数据在挂载盘上持久化

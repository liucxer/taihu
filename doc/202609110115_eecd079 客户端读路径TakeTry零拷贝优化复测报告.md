# eecd079 客户端读路径 TakeTry 零拷贝移交优化复测报告

> 对应提交：`eecd079`（perf: 客户端 Get 单帧响应 TakeTry 零拷贝移交收流节点缓冲（bufpool 精确尺寸池 + netpoll 一帧一节点））
> 对比基线：`ca28a75`（202609102330 客户端读路径 ReadCopy 优化复测报告）
> 测试：3 服务端 × 3 客户端并行 RPC 读（各 32T/16C/4MiB×20000，loopback，客户端+服务端同机 128.12）
> 测试时间：2026-09-11 01:14 ~ 01:16

## 1. 测试目标

验证客户端读路径 TakeTry 零拷贝移交优化的效果：单帧整响应（4MiB chunk 一帧）从 netpoll 收流节点
直接移交调用方缓冲（`UnsafeLinkBuffer.TakeTry`），彻底消除客户端收帧汇入拷贝，
对比复测客户端 pprof（memmove/Syscall6 占比）、进程 CPU、聚合带宽与延迟。

## 2. 测试环境

| 项目 | 值 |
| --- | --- |
| 服务器 | 100.71.128.12（客户端+服务端同机，loopback 127.0.0.1，aarch64 96 核） |
| 数据设备 | /dev/nvme1n1、nvme2n1、nvme3n1（O_DIRECT + libaio） |
| 元数据 | /tmp/tdb1、/tmp/tdb2、/tmp/tdb3（pebble，复用基线数据，WAL 回放 ~40000 key/端） |
| 服务端 | /tmp/taihu-server.new（eecd079）×3，:50051/52/53，pprof :6061/62/63 |
| 客户端 | /tmp/taihu-rpc-bench.new（eecd079）×3 |
| 对象 | 4 MiB × 20000（80 GiB/端点），chunkSize=4MiB 单帧传输，netpoll 一帧一节点（inputNodeSize = 4+maxFrameTotal） |

## 3. 测试方法

1. 数据复用基线：/tmp/tdb1/2/3 元数据完整（基线写入的 p4m-s1/2/3 各 20000 key 未变），跳过写灌，直接读；
2. 3 客户端并行 `-mode read -size 4194304 -threads 32 -conns 16 -count 20000 -keys-prefix p4m-s{1,2,3} -latency -cpuprofile <c{n}.cpu>`；
3. 全程 `mpstat -P ALL 1`、`iostat -d nvme1n1 nvme2n1 nvme3n1 1`、`/proc/net/dev`（lo 差分）逐秒采样；
4. 读测期间抓 3 服务端 pprof（:6061/62/63 各 30s）；
5. 客户端 cpuprofile 与服务端 pprof 拉回本地 `go tool pprof` 分析。
6. 说明：压测脚本无参 `wait` 等待常驻采样器导致外壳超时被杀，但 3 客户端均在 ~15s 内正常完成、全部日志与采样文件完整，数据有效。

## 6. 结论

1. **TakeTry 零拷贝移交生效**：单帧整响应从 netpoll 收流节点直接移交调用方缓冲（bufpool 精确尺寸池
   GetExact + 一帧一节点 + flagInputAligned 标记），客户端 memmove 由 40.7~41.8%（ReadCopy 单拷贝）
   进一步降至 12.9~15.1%，且剩余 memmove 99.5% 为未命中回退路径的 ReadCopy；客户端进程 CPU
   每实例 -30%（6.4~6.7 → 4.3~4.6 核）。
2. **带宽与延迟大幅提升**：聚合 13695 → 15945 MiB/s（+16.4%）、磁盘聚合 15.3 GB/s（单盘 4.88~5.21 GiB/s，
   距单盘读极限 ~6.6 GiB/s 仍有余量）、延迟 p50 -46%。
3. **客户端瓶颈转移**：收帧零拷贝后客户端 CPU 由 recv syscall（76~78%）主导，memmove 仅剩回退拷贝；
   服务端形态不变（sendmsg 92.9%）。整机 busy 30.5% 且逐核均匀，lo PEAK 16.2 GB/s 贴近实测上限。
4. **结论**：TakeTry 达成目标——客户端收帧路径已无必然拷贝，聚合读上限当前受限于 loopback 吞吐 +
   客户端 recv syscall；要再突破需绕开同机 loopback（跨机部署）或进一步降低 recv 次数（更大帧/批量收）。

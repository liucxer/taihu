# b93df7f 单客户端 + 三服务端 bench cluster 4M IO 三盘性能测试报告

## 1. 测试目标

用 **`taihu bench cluster`**（单客户端进程，SDK 查 TiKV 注册表自动连接集群全部实例）在 **1 客户端 + 3 服务端 + 3 块裸盘**（nvme1/2/3n1）拓扑下测 4 MiB IO 读写带宽，验证：
1. 单客户端能否以"每盘保持单盘打满并发"的方式测到三盘聚合上限（写 ~7.6 GiB/s、读 ~19 GiB/s）。
2. 客户端并发换算：单盘最佳读 16t / 写 8t → 三盘读 48t / 写 24t。
3. 采集应用层带宽延迟、三盘物理磁盘带宽（iostat 稳态口径）、整机与进程 CPU、零拷贝帧统计。

## 3. 测试方法

```bash
# 服务端 ×3（各自一盘，无 --batch）
/tmp/taihu.b93df7f server --listen 100.71.128.13 --db /var/taihu-db/nvme{1,2,3} --dev /dev/nvme{1,2,3}n1 \
  --server-name n13-nvme{1,2,3} --pd <三节点PD>

# 写（24t / round-robin / p1，count=50000）
/tmp/taihu.b93df7f --pd 100.71.128.11:2379,100.71.128.12:2379,100.71.128.13:2379 --client-name t13c \
  bench cluster --mode write --transport auto --write-routing round-robin \
  --size 4194304 --count 50000 --threads 24 --conns 8 --pipeline 1 --latency --report-interval 5s

# 读（48t / p1，count=50000，--preload 预热路由缓存）
/tmp/taihu.b93df7f --pd 100.71.128.11:2379,100.71.128.12:2379,100.71.128.13:2379 --client-name t13c \
  bench cluster --mode read --transport auto \
  --size 4194304 --count 50000 --threads 48 --conns 8 --pipeline 1 --latency --preload --report-interval 5s
```

- 并发换算：单盘 bench single 最佳读 16t（16 在途，打满单盘）/ 写 8t → 三盘各保持单盘打满并发 → 读 48t、写 24t。
- 写路由 `round-robin` 保证三盘均衡；读按写时建立的 key→实例索引自然分散。
- `-transport auto`：三 server 同机 → 全部走 shm。
- 每次测试后台并行采集 iostat / sar / pidstat；磁盘带宽按 **iostat-bw 稳态口径**统计（剔首行开机累计、爬升、收尾残差）。

## 9. 结论

1. **单客户端 bench cluster 可测到三盘上限**：写 24t → **7.61 GiB/s**（三盘 util ~99%，每盘 ~2537 = 单盘写上限）；读 48t → **稳态 19.0 GiB/s**（三盘 util 100%，每盘 ~6340 ≈ 单盘读上限 97%）。
2. **并发换算成立**：单盘最佳并发（读 16t / 写 8t）按盘数线性放大（读 48t / 写 24t）即可喂满每盘队列，聚合带宽 = 单盘上限 × 盘数。
3. **读均值 17702 低于稳态 19021**：读仅 11.3s（写 30s 灌数据量限制 count=50000），ramp 占比较高；稳态速率 19336 与磁盘稳态 19021 吻合（98.4%），与 fio 三盘读 19359 持平。
4. **写较 fio 提升 +12%**：SDK 直连（无 FUSE 层）24 在途即打满三盘写；fio 需 4 卷×32j×d16=2048 在途，bench cluster 仅需 24 在途。
5. **代码修复**：`bench cluster` 补注册 `--pipeline` flag（此前命令必然报错无法运行），建议合入。

4. **最终结论**：单客户端 + 三服务端 + 三盘 bench cluster 稳定达到 **读 ~18.2 GiB/s、写 ~7.4 GiB/s**（磁盘持续打满，SDK 直连缩放三盘上限），调长测试时长不改变结论。

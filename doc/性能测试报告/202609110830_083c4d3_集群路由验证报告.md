## 2. 验证方法与结果

### 2.1 实例注册与发现（心跳）

`ListInstances` 扫到 **9 个实例**，容量/已用随心跳刷新，离线判定依据独立 `last_heartbeat` 字段。

```
instances: 9
  n11-nvme1 node=100.71.128.11 addr=100.71.128.11:50051  used=1.4G cap=377G
  n11-nvme2/3 ...（同上）
  n12-nvme1/2/3 node=100.71.128.12 ...
  n13-nvme1/2/3 node=100.71.128.13 ...
```

### 2.2 写路径：本地优先 + 三盘均衡

客户端 node=100.71.128.12，写 200 个 1MiB 对象（经 `rpccluster.Storage.Put`，Picker 本地优先）。

```
key distribution by instance:
  n11-* : 0 keys（远端不落）
  n12-nvme1 : 117 keys (LOCAL)
  n12-nvme2 : 117 keys (LOCAL)
  n12-nvme3 : 102 keys (LOCAL)
  n13-* : 0 keys（远端不落）
```

- 本地优先 **100%**：全部写入同 node（128.12）三盘，远端实例 0 写入
- 三盘均衡（117/117/102，随机选择）
- 说明：因验证时重复执行一次 write，部分 key 两次随机落点不同致统计数合计 336（>200），
  不影响"本地优先 100%、远端 0"结论

### 2.3 索引锚定（异步批量落盘）

扫描 `/taihu/index/` 前缀：

```
index entries: 200 (expected 200)
  -> n12-nvme1: 71
  -> n12-nvme3: 62
  -> n12-nvme2: 67
```

- 200 条索引**全部异步落盘**，与写入 key 一一对应
- 索引目标全部指向本地实例（n12-*），与写分布一致（71/67/62）

### 2.4 读路径：同 node 本地直查

node=100.71.128.12 读同一批 200 key：

```
read 200 keys: localHit=200 remoteHit=0 sourceHit=0 miss=0
```

本地直查 **100%** 命中，无远端/回源。

### 2.5 读路径：跨 node 索引定位远端

node=100.71.128.11（模拟 128.11 客户端，本地实例无数据）读同一批 200 key：

```
read 200 keys: localHit=0 remoteHit=200 sourceHit=0 miss=0
```

本地 0 命中 → **索引定位远端读 100%** 命中（经 `/taihu/index/` 路由到 n12-* 实例）。

### 2.6 回源兜底

读 50 个不存在的 key（前缀 miss，无本地/索引）：

```
read 50 keys: localHit=0 remoteHit=0 sourceHit=50 miss=0
```

全 miss → **回源回调 100%** 兜底（`SourceGetter` 拉远端源）。

## 3. 验证中发现并修复的问题

| 问题 | 现象 | 根因 | 修复 |
|------|------|------|------|
| rawkv Scan limit=0 返回空 | 实例发现 0 个（Get 正常） | tikv client-go rawkv 的 `Scan` limit<=0 视为"返回 0 条"，非"不限" | `ListInstances` 传固定正数 10000（同时满足 MaxRawKVScanLimit 上限约束） |
| Scan limit 过大报错 | `limit should be less than MaxRawKVScanLimit` | 1<<20 超上限 | 收敛为 10000 |

修复文件：`internal/cluster/register.go`（ListInstances）。

## 4. 结论

三节点九盘集群部署成功，**"首写本地 + 索引锚定 + 回源兜底"路由全链路验证通过**：

| 路径 | 验证点 | 结果 |
|------|--------|------|
| 注册/发现 | 9 实例心跳在线、容量上报 | 9/9 |
| 写 | 本地优先（同 node 实例） | 100%（远端 0） |
| 写 | 三盘均衡 | 117/117/102 |
| 索引 | 异步批量落盘 key→实例 | 200/200，全部指向本地 |
| 读（同 node） | 本地直查优先 | 200/200 |
| 读（跨 node） | 索引定位远端读 | 200/200 |
| 读（miss） | 回源兜底 | 50/50 |

数据面（netpoll 零拷贝、4MiB 帧、final 位）未改动，集群仅增加定位层，验证过程中无数据面异常。
